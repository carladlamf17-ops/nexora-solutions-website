Cybersecurity / Report 03

The screenshot says “paid.” What do your transactions show?

The scam works when a store releases goods based on an image. Two orders can cost the same and a genuine screenshot can belong to a different sale.

Nexora SolutionsIssue 01November 9, 2026

The first order costs Bs. 1,250. The second costs the same and comes with a convincing screenshot until you read the reference: 4821 again. In this reconstruction, the shop’s account shows one credit. Deliver both orders and the same transaction will have been used for both sales.

Banesco’s public guide explains that operations are visible in the account’s transactions. The exact location of that feature varies by bank. See sources

Simulated example

Read the text in the image
  • Order A: Bs. 1,250 · fictional reference 4821
  • Order B: Bs. 1,250 · screenshot repeats reference 4821
  • Transactions: only one credit appears

Did the money actually arrive? Simulated scenes

The receipt you were sent

An image displays an amount and reference. It could be altered, reused, or sent before a credit is confirmed.

Your bank’s record

Open your bank yourself, select the receiving account, and find a transaction matching the order. Use the reference if available and match each credit to just one delivery.

Practical guide

What to do, step by step

  1. Record the order, amount, date, and available reference.
  2. If the transaction is missing, hold the order and any refund. Contact the bank if its app is unavailable.
  3. If you already handed it over, save the order, screenshot, and chat to report the incident.
